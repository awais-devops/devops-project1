# 🚀 DevOps CI/CD Pipeline Project

This project demonstrates a complete **DevOps workflow** from code commit to live deployment using modern tools.

---

## 🔧 Technologies Used

- Linux (Ubuntu)
- Git & GitHub
- Docker (Containerization)
- GitHub Actions (CI/CD)
- AWS EC2 (Cloud Hosting)
- Nginx (Web Server)

---

## ⚙️ Project Features

✅ Automated CI/CD pipeline  
✅ Dockerized application  
✅ Auto deployment on every push  
✅ Secure SSH-based deployment  
✅ Live hosting on AWS EC2  
✅ Version control & rollback support

## 🔄 Workflow

1. Developer pushes code to GitHub  
2. CI/CD pipeline triggers automatically  
3. Docker image is built and pushed  
4. EC2 server pulls latest image  
5. Container restarts with new updates
